# Dashboard Analítico de Vendas Globais - Power BI

Este repositório contém um **dashboard analítico de vendas globais**, desenvolvido no Power BI para estudo e prática de Data Analytics na ferramenta.
O objetivo foi **explorar, transformar e visualizar dados de vendas**, além de responder perguntas com os dashboards., criando uma visão clara e estratégica dos principais indicadores.
